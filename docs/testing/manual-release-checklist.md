# 发布前人工测试检查单

本检查单用于发布前在真实游戏中验收。自动化测试重点保护存档、协议、权限、凭据和核心播放回归；本单补充真实游戏中的玩法、界面、音视频与多人体验验收。执行时记录源码版本、操作系统、显卡/驱动和使用的模组或资源包。

## 使用方式

- **快速档**：每次发布必做。执行第 0 章全部条目和其余章节中带 `[快]` 的条目。
- **完整档**：升级 Minecraft/NeoForge、改动播放链路或大规模重构后做，执行全部条目。
- 标记 `★` 的条目仍需人工确认，已有自动化只能证明其中部分边界；具备所需环境时，完整档应执行。缺少环境的条目记录为未验证，不记作通过。
- 按章节顺序执行。后面的章节复用前面搭好的设备，不要打乱顺序。
- 任一条目失败：记录复现步骤、相关设备状态、`/ncpbc status`、`/ncpbc video status` 与日志位置，修复后重测相关路径。

## 0. 准备

- [ ] 执行 `bash gradlew build`，确认输出 `BUILD SUCCESSFUL`（包含 `test` 和生产 JAR 校验）。
- [ ] 执行 `bash gradlew platformTest`，确认输出 `BUILD SUCCESSFUL`。
- [ ] 使用独立测试游戏目录和测试世界；需要修改凭据、配置或白名单时先备份测试数据。
- [ ] 启动专用服务器（`runServer`）和两个客户端：客户端 A 为 OP4，客户端 B 为普通玩家。快速档中只有第 8 章需要 B，可以到时再开。
- [ ] 准备素材：一个有字幕的多 P 视频 BV 号、一个 av 号链接、一个正在直播的直播间号、一个已下播的直播间号。
- [ ] 创造模式拿齐：现代化唱片机 ×2、直播机、歌词投影仪、视频投影仪 ×2、音响 ×2、中控台、MP4、Pad、媒体管理工具、隐形耳机、猫耳无线耳机、全息眼镜，以及 NetMusic 电脑、CD 刻录机、广播喇叭、漏斗、红石比较器。
- [ ] 进入世界且没有媒体播放时记录 `/ncpbc video status` 和 `/ncpbc dolby source status`，作为第 10 章的资源基线；需要观察内存趋势时按[内存诊断](../memory-diagnostics.md)开启日志。`/ncpbc status` 只提供最近播放快照。

## 1. 登录与刻录

- [ ] [快] NetMusic 电脑点击“B站登录”，扫码成功；重启客户端后仍为已登录。
- [ ] 在客户端退出后，改动测试游戏目录内 `net_music_can_play_bili-private/bili-credentials.json.enc` 的一个字节，启动后确认旧凭据不被接受，需要重新扫码；跨机器复制的拒绝加载另作可选检查。完成后恢复备份或重新扫码。
- [ ] [快] BV 号、av 号、视频链接各刻一张唱片，三张都能生成。
- [ ] 多 P 视频填写分 P 序号 2 刻一张，播放内容是第 2 P。
- [ ] 分 P 填 0 或非数字，提示错误且不生成唱片。

## 2. 唱片机与影音系统

在出生点附近搭建，后续章节复用这台唱片机。

- [ ] [快] 手持唱片右键唱片机：插入并开始播放；再右键：弹出唱片。
- [ ] [快] Shift + 右键打开控制界面，逐项操作并确认：暂停后声音停、播放后从原处继续；重播从头开始；单曲循环下曲终自动重播；拖动进度条后声音跳到对应位置；调音量后响度随之变化。
- [ ] 切到冒险模式：仍能拖动进度，调音量无效；切回创造模式。
- [ ] 漏斗向空唱片机输入唱片，传输完成后自动播放。
- [ ] “播完提取”模式：播放中漏斗取不走唱片，自然播完后被取走。
- [ ] “自由提取”模式：漏斗随时取走唱片，播放立即停止。
- [ ] 红石模式依次切换并确认：
  - 高信号：通电时播放，断电时暂停，再通电从暂停处继续。
  - 低信号：通电时暂停，断电时播放。
  - 脉冲切换：第一次脉冲开始播放，第二次暂停，第三次从暂停处继续。
  - 忽略红石：通断电都不影响播放。
- [ ] 红石比较器：空唱片机输出 0；播放中从 1 逐步升到 15；暂停时保持不变；自然停止后归 0。
- [ ] [快] ★ 手持歌词投影仪、视频投影仪、音响分别右键唱片机，出现“已存储连接目标”后放置；三种设备均自动连接，并分别出现歌词、视频画面或声音。
- [ ] ★ 唱片机播放中，再绑定并放置第二台视频投影仪，画面立即出现。
- [ ] ★ 把一台视频投影仪重新绑定到第二台唱片机，第一台唱片机不再驱动它。
- [ ] 歌词投影仪：调整朝向、俯仰、高度、偏移和缩放，画面随之变化；切换静态、轮换·主、轮换·副三种模式；开关 AI 字幕。
- [ ] [快] 视频投影仪：切换 720P 和 1080P，画面清晰度变化，音画同步；设置页显示请求画质、实际画质、codec 和 backend。
- [ ] 在游戏启动器的 JVM 参数中加入 `-Dncpb.bili.video.codec_policy=h264` 后重启客户端，视频投影仪设置页的 codec 显示 H.264，且播放正常。
- [ ] 音响：两台分别分配左、右声道，站在中间能分辨声音来自对应方位；静音后无声；音量 0 无声、2 倍明显比 1 倍响。
- [ ] 走出唱片机播放范围后声音和画面停止，返回后从当前进度继续，不从头播放。

## 3. 直播机

- [ ] [快] 直播机填入直播间号开始播放，有声音；连接视频投影仪后有画面，口型与声音没有明显错位。
- [ ] 分别用 `live:房间号` 和直播间完整链接开播。
- [ ] 已下播的直播间：提示未开播，不进入播放状态。
- [ ] 音响右键直播机后，音响能输出直播声音。
- [ ] NetMusic 广播喇叭填 `live:房间号`，能播放音频。

## 4. 中控台

- [ ] [快] 手持中控台物品右键唱片机，再放置中控台，界面显示已绑定该唱片机。
- [ ] 编辑器中添加屏幕、字幕、空间音源各一个，拖动并修改属性后保存；关闭再打开，内容都在；上一轮自动保存尚未完成时继续修改并关闭，再打开仍保留最后一次已确认提交的内容。
- [ ] 走出中控台消费范围后媒体停止，返回后恢复（以当前设备配置与服务端范围为准）。
- [ ] 另放一台绑定直播机的中控台，屏幕和音频元素都有输出。
- [ ] 客户端 B 在冒险模式且无管理员权限时打开中控台编辑器，被拒绝；恢复可建造并由 A 授予该中控台的编辑权限后，A 正在编辑时 B 打开显示被占用。（需要 B，可放到第 8 章一起做。）

## 5. MP4

- [ ] [快] 物品栏中拿起唱片，左键点击 MP4，唱片加入队列；空手右键 MP4，取出选中的曲目。
- [ ] 装满 18 张（MP4 容量上限）后，第 19 张放不进去，且唱片仍在鼠标上。
- [ ] [快] 手持 MP4 右键进入聚焦界面：上一首、下一首、播放/暂停、播放列表、视频开关、横屏、画质、字幕、音量、循环逐项操作，每项都有对应变化。
- [ ] [快] 底部 B站登录、顺序/随机/循环、列表、歌词及画质/字幕菜单的可用按钮有对应悬停线框；竖屏、横屏中线框与命中位置一致。登录浮层遮挡或横屏控制栏隐藏后，背后的按钮不显示悬停框。
- [ ] ★ 横屏时用鼠标点击屏幕内的按钮，点中的就是鼠标所指的按钮；双击同一按钮不会触发旁边控件。
- [ ] 暂停后拖动进度条，保持暂停；恢复播放后从所选进度继续。
- [ ] MP4 移出快捷栏后音频继续、画面停止；放回后画面恢复。
- [ ] 播放中退出并重进世界，媒体加载完成后从保存的进度续播，不从头开始。
- [ ] 暂停、停止或自然播完后分别退出并重进世界，不会因旧状态意外自动播放。
- [ ] 把正在播放的 MP4 丢到地上：掉落物继续承载原播放，会话和进度不重置；捡回来后继续播放。

## 6. Pad

- [ ] [快] 把唱片放到草稿 Pad 上，手持右键打开地图，从右侧媒体库拖一首歌到地图上，生成 Pin。
- [ ] 选中 Pin，逐项调整显示状态、触发半径、触发方式、循环和音量；拖动 Pin 微调位置；删除 Pin。
- [ ] [快] 点击“发布副本”，背包中得到锁定副本；锁定副本不能修改媒体库或点位，也不能放入或取出唱片。
- [ ] 修改草稿后，锁定副本上能看到同样的修改。
- [ ] 把点位设为隐藏，并将触发方式设为进入半径：地图上不显示图标，走进触发范围后仍能自动播放。
- [ ] 编辑时快速连续修改，然后立即关闭界面；重新打开后，最后一次修改仍在。
- [ ] 执行 `/ncpbc pad cache refresh`，地图重新生成且显示正常。

## 7. 耳机、全息眼镜与绑定 ★

- [ ] [快] ★ 媒体管理工具右键唱片机，在右上槽放入隐形耳机，点击向下箭头绑定；戴上耳机后能听到，走出约 64 格或换维度后听不到。
- [ ] ★ 用媒体管理工具把 MP4、Pad 分别绑定到猫耳无线耳机，戴上后都能听到。
- [ ] ★ 全息眼镜绑定唱片机：戴上后普通投影画面在本地隐藏，HUD 显示视频；用配置的全息眼镜按键（默认 `H`）打开配置界面。
- [ ] ★ 全息眼镜绑满 4 个媒体源后，第 5 个绑定被拒绝。
- [ ] ★ 点击“解绑”后不再输出，重新绑定后恢复。

## 8. 多人与同步

本章需要客户端 B 在线。

- [ ] [快] A 播放唱片机，B 走进范围后自动开始收听，两边进度一致。
- [ ] ★ A 戴上已绑定的耳机，B 站在旁边听不到耳机内容。
- [ ] ★ B 在收听播放中的世界设备时断线重连，重新进入消费范围后恢复收听，A 的播放不受影响。
- [ ] A 播放中切换维度再回来，原维度没有残留声音，回来后播放正常。
- [ ] A 手持媒体管理工具 Shift + 右键空气，举报附近音源；A 作为 OP 收到通知；B 重复举报同一音源时只合并为一条。
- [ ] ★ 在可控的流失败条件下观察地址重新解析与续播，记录日志、会话和进度；同一逻辑会话仅有一次自动重试机会。重试仍失败应明确停止或显示失败，不能无限重试或影响另一设备的新播放。短暂断网和长时间播放只能作补充观察，不能单独证明过期地址刷新。

## 9. 白名单与权限

- [ ] [快] 在 `config/net_music_can_play_bili-common.toml` 中开启链接白名单：未加白的 BV 无法刻录或播放，提示中包含管理员联系方式。
- [ ] `/ncpbs whitelist add <BV号或视频链接>` 加入后可播放；`/ncpbs whitelist add live:<房间号>` 加白后直播可播放。
- [ ] 播放中把该条目移出白名单，正在播放的设备停止。
- [ ] `/ncpbs whitelist review`：活动和历史页签切换、翻页；键盘 `↑`/`↓`、`Page Up`/`Page Down`、`Home`/`End`、`Enter` 预览、`Delete` 删除都有效。
- [ ] 删除时备注为空被拒绝；删除成功后停留在原分页，并选中相邻条目。
- [ ] 预览界面：`←`/`→` 跳 5 秒，`↑`/`↓` 切换条目，`Space` 暂停或继续。
- [ ] `/ncpbs whitelist export` 生成 CSV，用表格软件打开，条目和评论完整。
- [ ] B 执行 `/ncpbs whitelist add <BV号>` 被拒绝。
- [ ] ★ 若安装 LuckPerms：给 B 授予 `net_music_can_play_bili.whitelist.manage` 后命令可用，撤销后不可用。
- [ ] 测完关闭白名单，或移除测试条目。

## 10. 兼容、资源与持久化

- [ ] ★ 若安装 AreaControl：站在区域内外，音频隔离正确。
- [ ] ★ 若安装 Iris 光影包或常用地形模组：Pad 地图和中控台地形预览显示正常。
- [ ] 连续切换 10 次唱片和画质，停止播放并等待异步关闭后，比较 `/ncpbc video status`、`/ncpbc dolby source status` 与第 0 章基线，确认没有遗留媒体会话或输出；若已开启内存日志，重复操作后观察 NCPB 自有资源是否收敛，不要求 JVM/驱动内存立即回到相同数值。
- [ ] 关闭服务器再启动：唱片机（含音量、红石和提取模式）、中控台布局、Pad 点位、MP4 队列、白名单和审核记录都保持原样。
